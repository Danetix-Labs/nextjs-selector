# nextjs-selector

## 0.1.0

### Minor Changes

- 3ca8e69: `Select.Announcer` — живая область, объявляющая число найденных вариантов
  и изменения выбора. В готовом компоненте включена по умолчанию.
- df018d2: Асинхронная загрузка опций: `loadOptions` с debounce, отбрасыванием устаревших
  ответов, состояниями `Select.Loading` и `Select.LoadError`.

  Исправлено: подписчики читали видимые опции через ref и могли получать
  устаревшие данные — список переехал в store.

- aa44492: Составные компоненты `Select.*` поверх headless-ядра и аудит axe в тестах.
- 4618389: Создание опций на лету (`creatable`, `onCreate`) и компонент
  `Select.Virtualized` — виртуализованный список без ручной сборки.
- 107c0b7: `<Select>` и `<MultiSelect>` для обычного случая — один элемент вместо дюжины,
  составные части остаются доступны под тем же именем.

  Исправлено позиционирование: триггер сам объявляет CSS-якорь, а `Select.Root`
  рендерит позиционированную обёртку — без этого список уезжал в угол страницы.

- 3369d8c: `useFormFields` рендерит выбор в скрытые поля формы: работают FormData,
  обычная отправка формы и Server Actions React 19 без JavaScript на приёме.
- 407a1de: Опции параметризованы своим типом: поля потребителя (иконки, аватары, роли,
  любые метаданные) доходят до функции-рендера типизированными.
- 14a8ff9: Группы опций (`group` в `SelectOption`), `Select.Chips` с удалением значений
  и `asChild` для подмены элемента в `Trigger`, `Item` и `Content`.
- 185c873: Headless-ядро: `useSelect` с APG-клавиатурой, фильтрацией, одиночным и
  множественным выбором, плюс prop getters с ARIA и data-атрибутами для стилизации.
- 4f8f6b7: Подгрузка страницами: `loadOptions` принимает курсор и может вернуть
  `{ options, nextCursor }`. Компонент `Select.LoadMore` догружает следующую
  страницу при прокрутке к концу списка.
- 2c20013: Слой позиционирования на нативном Popover API и CSS anchor positioning
  с фолбэком в обычный поток. Опциональный `nextjs-selector/styles.css`.
- 9b86c81: Подписи под пунктом (`description` в опции) и навигация по сетке (`columns`):
  стрелки вверх-вниз ходят через строку, влево-вправо — по одному.
- c618de5: Подсветка совпадений в подписях, лимит выбора `max`, «выбрать всё»
  (`Select.SelectAllButton`) и закреплённые значения `pinned`.
- 793ef1b: Нижняя шторка на узких экранах — опция `sheet` с настраиваемым `sheetMedia`.
  По умолчанию выключена.
- 641ff06: Слоты `Select.Header` и `Select.Footer` (плюс пропсы `header` / `footer`
  готового компонента) и хук `useSelectedCount` для счётчиков.
- d36476e: Состояния `disabled`, `readOnly`, `required` и `invalid` на уровне `Select.Root`,
  плюс бюджет размера бандла в CI.
- 9919605: Перестановка чипов (`reorderable`, мышью и с клавиатуры), отмена удаления
  (`Select.UndoRemove`) и кеш ответов асинхронного источника (`cache`).
  Исправлено: `Select.Value` игнорировал порядок выбора.
- c953594: Typeahead по набранным символам и постраничная навигация PageUp/PageDown —
  клавиатура ядра доведена до паттерна APG combobox.
- cd0af65: Виртуализация строк разной высоты: вместо `itemHeight` можно передать
  `estimateHeight`, и строки сообщат настоящую высоту после отрисовки.
- b23d8df: Встроенная виртуализация списка с фиксированной высотой строки: в DOM попадает
  только видимое окно, подсветка автоматически удерживается в зоне видимости.

### Patch Changes

- 895cb53: Перевёрнутый вверх список больше не отрывается от поля на высоту метки:
  позиция считается от триггера, а не от края обёртки.
- 0dccee9: Исправлен контролируемый режим: виджет менял значение сам, игнорируя родителя.
  Теперь `onValueChange` сообщает о намерении, а значение принадлежит родителю.
- acee0bb: Демо-приложение на Next.js 16 в `examples/demo` со всеми возможностями,
  его сборка проверяется в CI.
- f060f78: Измерение стороны списка throttled до одного раза за кадр и выполняется после
  отрисовки — иначе высота читалась нулевой и список не переворачивался.
- 309c266: Некорректный ответ `loadOptions` теперь объявляется ошибкой загрузки, а не
  роняет необработанное исключение внутри промиса.
- 6e231d9: Бессмысленные настройки приводятся к разумным: `columns` меньше единицы
  больше не ломает навигацию, отрицательный `max` читается как ноль.
  Перестановка с нецелым индексом отвергается.
- 4042608: Исправлено позиционирование: список больше не уезжает в угол страницы.
  Верхний слой стал опциональным (`topLayer`), кнопка очистки вынесена из
  триггера. Добавлены браузерные тесты на Playwright.
- 21b2413: Исправлено по итогам ревью: `readOnly` не блокировал «выбрать всё»,
  перестановку чипов и отмену удаления; кеш обрывал постраничную загрузку;
  автоскролл при разной высоте строк считался по оценке вместо реальных высот.
- 163544d: Исправлена таблица стилей: правило высоты списка из режима шторки утекало
  в обычный выпадающий список, растягивая его на 85% экрана.
- a558255: Окно виртуализации больше не уходит за конец списка, когда опций стало
  меньше, а контейнер остался прокрученным.
