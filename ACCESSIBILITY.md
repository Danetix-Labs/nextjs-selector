# Доступность

## Что проверяется автоматически

| Уровень | Чем | Что доказывает |
| --- | --- | --- |
| Структура ARIA | axe в юнит-тестах | роли, обязательные потомки и родители, имена |
| Дерево доступности | Playwright | имена, состояния и живые области в реальном браузере |
| Клавиатура | юнит-тесты + Playwright | весь путь проходится без мыши |

Прогоны идут на каждом наборе возможностей: группы, чипы, виртуализация,
состояния, сетка, `dir="rtl"`.

## Чего автоматика не проверяет

Ни axe, ни снимки дерева не отвечают на главный вопрос — **понятно ли это на
слух**. Они не знают, когда скринридер решит заговорить, насколько он будет
многословен и не перебьёт ли сам себя. По данным WebAIM Million 2026 страницы
с ARIA в среднем содержат больше ошибок, чем страницы без неё: разметка,
проходящая автоматический аудит, вполне может быть неудобной в работе.

Поэтому **соответствие WCAG 2.2 AA не заявляется**, пока не пройден ручной
прогон ниже.

## Чек-лист ручного прогона

Пройти в трёх связках: **NVDA + Firefox**, **JAWS + Chrome**, **VoiceOver +
Safari**. В каждой — с закрытыми глазами или выключенным монитором: если
сценарий проходится только подглядывая, он не пройден.

### Одиночный выбор

- [ ] Виджет объявляется по имени поля и как «комбобокс», а не «кнопка»
- [ ] Объявляется свёрнутое состояние и текущее значение
- [ ] Открытие объявляет, что список раскрыт, и число вариантов
- [ ] Стрелки читают опции; активная объявляется целиком, включая описание
- [ ] Отключённая опция объявляется недоступной, а не пропускается молча
- [ ] Выбор объявляется, список закрывается, фокус остаётся на триггере
- [ ] Esc закрывает список и объявляет это

### Множественный выбор

- [ ] Список объявляется как допускающий несколько значений
- [ ] Выбор и снятие объявляются отдельно, с названием значения
- [ ] Состояние «выбрано / не выбрано» слышно на каждой опции
- [ ] Чипы доступны обходом, у кнопки удаления есть внятное имя
- [ ] Backspace снимает последнее значение и сообщает какое
- [ ] На лимите (`max`) попытка добавить не проходит молча

### Поиск и загрузка

- [ ] Поле поиска объявляется отдельно от самого виджета
- [ ] После ввода объявляется число найденного, без зачитывания всего списка
- [ ] «Ничего не найдено» слышно
- [ ] Состояние загрузки объявляется, но не перебивает ввод
- [ ] Ошибка загрузки объявляется

### Клавиатура

- [ ] `↑` `↓` `Home` `End` `PageUp` `PageDown` работают в списке
- [ ] Набор букв прыгает к опции; повтор буквы перебирает варианты
- [ ] `Tab` уводит из виджета, не оставляя список открытым
- [ ] `Alt` + стрелки переставляют чипы, и перестановка объявляется
- [ ] В сетке стрелки ходят в двух измерениях

### Мобильные

- [ ] VoiceOver на iOS: шторка объявляется как отдельная область
- [ ] Свайп-навигация доходит до всех опций
- [ ] Цели нажатия не меньше 44×44 точек

## Как записывать результат

Для каждой связки: версия скринридера, версия браузера, ОС, дата и список
пунктов, которые **не** прошли, с расшифровкой услышанного. Отрицательный
результат ценнее общего «работает»: он показывает, что именно чинить.

После прохождения всех трёх связок заявление о соответствии WCAG 2.2 AA можно
внести в README со ссылкой на протокол.
